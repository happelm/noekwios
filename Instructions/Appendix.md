# Appendix

## Lab environment

| Item | Value |
|---|---|
| Tenant | Trainer demo tenant, shared by all participants |
| Your account | `studentX` (X = your number) |
| Your groups | `studentXusers`, `studentXdevices` |
| Object names | Start with `studentX` |
| Devices | Trainer iPhone 14, iPhone XR and iPad – assigned by the trainer |

## Where to find it

| Topic | Path |
|---|---|
| Push certificate, ADE tokens | Intune admin center → Devices → Enrollment → Apple |
| VPP tokens | Intune admin center → Tenant administration → Connectors and tokens → Apple VPP tokens |
| Enrollment time grouping failures | Intune admin center → Devices → Monitor |
| Sign-in logs, What If | Entra admin center → Entra ID → Conditional Access |

## Logs on iOS

| Log | How |
|---|---|
| Company Portal | Shake the device or More → Send Logs, incident ID |
| Authenticator (SSO extension) | Send feedback → Having trouble → View diagnostic data |
