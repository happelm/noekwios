# Demo 8 – Kiosk iPad

**Module:** M8 Shared, kiosk and signage devices · **Duration:** 15 min · **Device:** iPad (supervised)

> **Draft:** This demo has not been run in this environment yet.

**Goal:** Turn the iPad into a single-app kiosk and back.

### Prepare

- iPad enrolled through ADE without user affinity (or reuse the supervised trainer iPad).
- Device restrictions profile with **Kiosk** → app to run (Microsoft Edge or a web clip), built **before** the day, not assigned.

### Show

1. Assign the kiosk profile, sync – the iPad runs only the kiosk app (Apple App Lock).
2. Home screen layout and lock screen message for a shared device.
3. Unassign the profile, sync – the iPad returns to the normal home screen.

### Point out

- Kiosk mode needs supervision.
- Userless ADE devices: still allowed from iOS/iPadOS 16 after the iOS 18 minimum (MC1454371).
- Frontline sign-in/out: Microsoft Entra shared device mode.

Sources: Learn – Apple device restriction settings (Kiosk); Apple device feature settings; Set up automated device enrollment for iOS/iPadOS; MC1454371.
